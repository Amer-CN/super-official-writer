- **动笔前询问领导意见的两条路径与各自问法**：写材料的总原则是「磨刀不误砍柴工，领导意见要询问」——很多人拿到一个题目，习惯性地就开始闷头写提纲、搭架子、找素材、填内容，但做这些工作之前一定要做准备工作，简言之就是询问领导意见；只有询问了领导意见，文章写出来才有用，不符合领导意见的稿子写得再好也是白费功夫。询问方式有两种。一是当面沟通，侧重了解领导对文章结构的提点、对重点工作的强调、对来年工作的展望，尤其注意领导是不是对某些理论情有独钟、对某项工作大谈特谈（这些就是要在文中有所凸显的部分），也要注意领导是不是已经帮你分好了段、分好了块。二是非当面沟通，很多时候领导工作忙，或者你与领导之间还有其他层级不便直接沟通，这时一方面要以古为师，看领导之前欣赏的稿子、念过的稿子、用过的稿子，揣摩他的谋篇布局；另一方面要多向领导身边人或中层领导请教，了解领导平时对文字的要求或喜好，尽量去贴近他平时的风格。作者的落脚建议是：不管拿到什么题目，先把功夫放到文章外、放到领导身上——比如同样是一篇讲规矩有纪律的学习心得，有的领导喜欢从一些负面典型谈起，有的领导就极度反感文中出现负面典型，只有了解了他们的意见，才能避免你写完再改、写完再删，浪费时间和心血。 → 写作方法论（速成3 S01；【疑似套装内重叠：25项技巧】）
- **动笔前的「由谁写、对谁写、为何写」三问及其判据**：询问领导意见之后，就要立即解决「由谁写、对谁写、为何写」三个大问题，从大框架上把握一篇文章该如何写。一是「由谁写」，决定文章的高度和宽度——写材料时要完成自身向领导的转变，把自己当成领导，材料要体现领导的水平、领导的高度、领导的思路、领导的想法；举例来说，×街道办、党政办的同志要同时为街道书记和主任各准备一篇向区纪委、全委会的述职述廉报告，两人的内容就要体现出较大差异性，书记侧重抓党建、抓队伍、抓廉政建设，主任可以更多地提如何管钱、管基建、管社会治理等具体事务，如果帮领导写出来的两篇稿子书记更务实、主任反而更务虚，就产生了角色的错位。领导的身份不同，对同一件事的语气也要有所变化：这个部门是行政口领导分管的，那党口领导即使要提出批评也要注意方式方法，可以表述成「希望××工作得到加强」；本身就是行政口领导讲话，对该部门就可以更直接地批评一番。二是「对谁写」，决定文章的角度和深度——即充分考虑材料的场合和面向群体，是面向全体干部职工的讲话、是面向上级的汇报、是中心组学习的发言，还是上交上级党组织审核的对照检查，要根据场合和「听众」的不同调整文章的角度。同样是一篇单位一把手的述职述廉材料，在上级召开的大会上述职述廉，与在本单位内面向全体干部职工述职述廉，大体内容可以一致，但语气、表述方式都要微调：向上级的请示汇报，要在完成上级布置工作的情况、落实全年计划任务的情况等内容上加以重点阐述；面向本单位干部职工述职，就要多贴近干部职工关心的问题，多讲讲为他们办了哪些实事好事。又比如为同一位领导准备两份稿子，一份是向上级汇报某项工作的汇报稿，一份是布置任务给下级的布置稿：汇报稿要精干、要突出重点，让上级快速明了已经做了什么、还要做什么，不需要过多解释说明；对下级布置工作，就要不厌其烦、要具体。三是「为何写」，决定文章的尺度和力度——每一份文件、每一份材料几乎都有它的意图，起草时要多想一想为什么要写这个文稿。领导要你出一篇介绍单位好经验好做法的宣传稿，就要注意对某些人某些事详细刻画，做到生动具体、方便宣传、引导舆论；要争取上级对某项工作更大的支持，就要如实叙述、适当强调面临的困难、简洁明了列出需要上级帮助的事项；为了提振干部队伍士气，就要在文中体现出为大家鼓鼓劲、加加油的意思，要让大家有感觉、有感动、有感情；为了对大家进行警示教育，就要严肃认真，甚至不妨上纲上线，才能起到当头棒喝的作用。为领导准备供发表的理论文章，若领导主要想从理论上对上级要求做出进一步诠释，文章中就可以适当引经据典，体现领导深厚的理论素养；若领导主要是向上级表决心外加推介本地的工作，那文章中就不妨生动、贴近地气一些。作者的总判断是：只要破解了「为何写」的问题，把握这些要求就成了一个很简单的事情；把「为谁写」「对谁写」「为何写」这些问题琢磨透了，具体的怎么写就是细枝末节的雕虫小技——「磨刀不误砍柴工，动脑想想最重要」这十四个字送给大家。 → 写作方法论（速成3 S02；【疑似套装内重叠：25项技巧】）
- **六类常用文稿的基本结构清单**：框架主要包括两部分，一个叫作结构，一个叫作标题；而结构又要从「基本结构」和「千变万化」两个大方面说起。所谓基本结构，就是每一篇文章、每一种文体都有其内在的规范，这个属于不变的内容，可直接照搬六类常用文稿的骨架：一篇年度工作总结，往往包括两个部分或者说三个部分——今年工作内容、经验体会或存在问题、下一步工作思路；一篇对照检查材料，往往包括存在问题、原因分析、下一步的整改措施三个部分；一篇述职述廉报告，往往也包括学习、职责、廉政、不足和下一步方向等四部分内容；一篇在××专项工作会议上的讲话（比如在安全生产工作会上的讲话），往往包括提出问题（肯定成绩，目前还存在的不足）、分析问题（思想上、行动上、作风上存在这些问题的原因）、解决问题（思想上、行动上、作风上如何行动）三个部分；一篇调研课题，同样往往出现为什么要做（意义）、做什么内容（努力方向）、怎么去做（具体方法）等部分；一篇学习心得，比如「两学一做讲奉献有作为」心得体会，就应该是从领会内涵、把握关键要求、推动落地生根等方面去着手。作者强调，在写材料之前这一部分的基础工作要自己来做：写文章不能够太过于叛道离经，不能够过于天外飞仙，尤其忌讳闭门造车；现在网络资源这么发达，基本功靠网络上多看文章多学习就可以基本掌握。这一部分就叫作掌握基本结构，以不变应万变。 → 结构方法（速成3 S03；【疑似套装内重叠：25项技巧】）
- **同一内容可选的三副骨架：递进式、并列式、前重后轻**：掌握基本结构之后是「千变万化，不离其宗」，常见的结构方式有三种。第一种是递进式的结构：比如××工作的总结，就按照指导思想、步骤、方法、成效、不足、体会等一路顺下来；比如「两学一做」学习教育总结，就是如何制订方案、开展党课、交流研讨、实地教学等等，这个就体现了层层递进的特点。第二种是并列式的结构：比如机关事务局的工作总结，就是按照资产管理、财务保障、后勤事务、车辆管理、公共机构节能等等，每一块做了什么、有什么经验，体现出布局合理、前后对称。第三种是前重后轻的结构：比如写一个单位的抓党建工作总结，当然可以按照组织建设、思想建设等五方面来进行，也可以把自己单位的重点、亮点工作放在前面——「两学一做」是今年最大的工作，那么就把开展好「两学一做」放到前面、要占较大篇幅，后面的队伍建设、廉政建设就可以稍微少一些比例，这种叫作前重后轻，也就是说重点工作放最前。关键的判断是：同样一篇「两学一做」的总结，可以按照递进式的时间顺序，组织领导有力、党课开展认真、交流研讨深入；也可以用并列式，强化三个保障，强化组织保障、强化党课保障、强化理论保障，或突出三个重点，以行促学、以查促改、以活动促做；还可以按照前重后轻，开展网络教学大课堂、实现全员全参与。就是说，同样的内容，你可以把它并列，也可以把它递进，也可以把它前后突出重点，文章是千变万化的。 → 结构方法（速成3 S04；【疑似套装内重叠：25项技巧】）
- **把小标题做成领导话语的改造版**：写标题的第二个技巧，是要把领导最想强调的东西放在小标题中。小标题不需要非常复杂，不需要过多地讲究一些遣词造句的技巧；相反，我们把领导平时挂在嘴边的一些话语稍加变化，就可以成为一篇讲话的小标题。做法一：年终工作总结往往就是××工作上了新台阶、××工作取得新进展，但是如果领导平时经常强调转型升级，你整个文章中标题都可以用「转型升级」这四个字——类似推动队伍转型升级、推动管理转型升级、推动党建转型升级。做法二：单位主要领导经常强调「共产党员是特殊材料制成的」，那么小标题里就可以把原来的「加强理想信念，提高党性修养」变成「熔炼特殊材料的纯度，把牢理想信念这个关键」，把「践行四个意识」变成「熔炼特殊材料的硬度，夯实四个意识这个基础」。可复用的公式是：取领导惯用语的核心意象（如「特殊材料」），加一个可变的维度词（纯度、硬度），再挂上本段要讲的具体内容（理想信念、四个意识）。 → 标题技巧（速成3 S05；【疑似套装内重叠：25项技巧】）
- **标题与段落内容的外延必须匹配：既不能过大也不能过小**：标题的选择中有几条易犯的边界错误。一是不能与内容不一致：比如这一段中明明说的是党性修养，标题里却是理想信念。二是不能过大或者过小：比如这一段明明就谈了一项工作，就是加强制度建设，标题就不能用「建章立制、执纪从严」，因为没体现；也不能明明写的是加强制度建设、严格执行纪律，标题里只有「推动建章立制」。与之配套的检验法是各级标题的服务关系——三级标题是为二级标题服务的，二级是为一级服务的，一级是为了题目服务的，题目是为文章服务的、要和文章的主体内容合二为一，所以整个文章要能够做到光看标题和题目，就能大概知道你的整个文章内容是什么。三是标题能出新固然很好，但有些情况下不出也没问题：比如在××单位，工作总结常常就是在干部工作方面、在组织工作方面、在人才工作方面、在自身建设方面，还是要请大家结合自己的实际，不要花里胡哨，要言之有物。 → 标题技巧（速成3 S06；【疑似套装内重叠：25项技巧】）
- **内容充实的两条具体改法：抽象词展开成具体定位、成效句配数据**：在内容方面重点强调：一篇文章想要显得比较充实，就不能过于空洞，每一句话要言之有物、要有东西支撑。改法一，把抽象的性质判断展开成具体定位——很多人习惯性地大笔一挥，「财政局工作性质特殊，需要我们更加……」，那特殊在哪儿呢？应当是「财政局是政府的大管家，地位重要、性质特殊，我们是大管家里面的工作人员，身处管钱管账第一线，所以职责重大、受人关注，需要进一步……」，这就叫作言之有物。改法二，给成效句配上数据——工作总结中常见的「×××工作取得了新进展，××工作明显取得提高」，那就要注意尽量用一些数字、数据来作支撑，要让领导知道你的工作取得新进展是有实际依据的，比如机关事务工作取得了新进步，那就要用今年得了××奖、领导有什么批示、机关经费运行下降多少、三公消费降低多少等等一系列的东西来支撑，这是许多人最容易忽视的问题。还有一条是要保证全面、不能漏掉任何一项：比如一篇总结里面，各处室的工作几乎都提到了，就是没提到××处室，那绝对不合适；但全面又不代表要面面俱到，还是要注重详略得当、要把握住重点——想展现的要多些，一般化的、常规的工作可以简单写。 → 写作方法论（速成3 S07；【疑似套装内重叠：25项技巧】）
- **句子要说完：做法之后必须落到成效**：语言方面最基本的一个要求，就是每一句要有每一句的样子、主谓宾要准确，同时句子要说完。反例：很多同志写了长长一句话，类似「××供电公司将员工队伍建设与教育实践活动紧密结合，坚持以人为本，内强素质、外树形象」，就有一种戛然而止的感觉——这句话说完了吗？并没有。应该这样写：「××供电公司将员工队伍建设与教育实践活动紧密结合，坚持以人为本，内强素质、外树形象，取得了较好效果。」也就是说，不光要写做法，还要写成效，大家可以体会一下。作者另附一条风格提醒：所有文章从前到后，要在行文习惯、表达方式、遣词造句等方面保持一致的风格，不能给人以乱七八糟、拼拼凑凑的感觉——一开始简洁明快，后面就不能啰唆；通篇都是通俗的语句，就不能引用一些拗口的词句；通篇文采飞扬，就不适合出现一些俗语；通篇都是短句居多，那么明显的长句子、组合句、复合句，都要把它改成短句。 → 修改方法（速成3 S08；【疑似套装内重叠：25项技巧】）
- **核稿必查的政治错误两类：政治性专名与约定俗成的提法**：任何一篇文章到了最后都要认真检查、反复核对，第二个要检查的就是不要出现政治错误。作者举了两类情形。一是政治性专名写错：比如写一篇文章「加强与民革、民建、民进等民主党派的沟通联系」，结果文章中间出现的是「民进党」，这就是政治错误。二是把一些约定俗成的、已经提出的口号改掉：比如「强富美高」「三个定位两个率先」，就不能写成强高美富、三个率先两个定位。 → 文字规范（速成3 S09）
- **引用古语以听众能否当场听懂为取舍标准**：引用古语的时候一定要注意，要浅显易懂。「水可载舟亦可覆舟」，大家听了就懂；「千里之行始于足下」，也很好；「雄关漫道真如铁」，也不错。如果用「陟罚臧否，不宜异同」，大家可能听得云里雾里，所以尽量避免。取舍标准不是典故是否典雅，而是听众能不能当场听懂。 → 词句升级（速成3 S10；【疑似套装内重叠：25项技巧】）
- **新人练写作从政务信息起步及其三条理由**：对于新人而言，怎么把文章练好呢？作者认为，还是从政务信息开始练起，理由有三条：一是政务信息说到底就是一个「是什么、为什么、怎么办」的过程，这个结构清晰，比较容易学习；二是政务信息篇幅偏短，所以文字要求简练、朴实；三是政务信息不会堆积太多的辞藻，也要求准确，所以对于大家培养良好的文风很有好处。练的次序是：写完政务信息后，可以尝试从基本的材料写起；还有就是给高手看很重要，多写、多改、多提高。 → 写作方法论（速成3 S11）
