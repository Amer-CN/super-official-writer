# 报告蒸馏层（历年政府工作报告 2000-2026）

> 来源：`sources/gongzuobaogao/` 国务院政府工作报告 27 份全覆盖（2000-2026，约 46.5 万字）。
> 用途：**写总结/计划/报告类大材料定调时查本层**——句式配比基准、对仗小标题规律、收尾金句谱系、权威提法口径（解决政策时效问题，口径下探至 2026 年报告）。金句原文见 phrase-library"政府工作报告金句（2000-2026）"节；底稿见 lingyun `distilled/notes/蒸馏底稿·政府工作报告.md`；统计脚本与明细见 lingyun `archive/analysis/vnv_stats.py / vnv_stats.md`。

## 句式基因基准（V+N / N+V 实测，校准 SKILL.md"文章类型判断"规则）

- **总结回顾段**：V+N 66.0% / N+V 34.0%（1917 句，27 份合计）；**部署安排段**：V+N 94.7% / N+V 5.3%（5923 句）。→ 写作方法论（句式配比）
- **规则校验**："总结 N+V≥40%"偏严——实测 34.0%，且仅 2000-2008 年达标（41.7%-89.7%），2010 年后多数年份走低（13.0%-34.5%，仅 2016、2020 年特例），按年代应放宽为**总结段 N+V ≥30%**；"计划 V+N≥60%"大幅保守——实测 94.7%（最低年 2013 也有 87.1%），权威部署段几乎通篇 V+N，**≥80% 才接近报告基准**。SKILL.md 已标注实测依据。→ 写作方法论（句式配比）
- **年代漂移规律**：早年总结段以"——经济快速发展。"式 N+V 成绩标题领起（2000-2008 最典型，N+V 占比最高 89.7%）；近年总结段越来越多用 V+N 动词领起（"一是着力稳企业保就业…"），N+V 最低降至 13.0%（2025；2021 年 13.2%）。写"新式"总结可两点并用：成绩定性句用 N+V，做法动词句用 V+N。→ 总结技巧（句式配比）
- **对仗小标题两代规律**：①总结小标题全 N+V（名词+定性词），标题后紧跟量化数据，领域排序稳定：经济→结构/创新→改革→生态→民生；②部署小标题全 V+N，2000-2012 多"动词+领域名词"单句式，2014 年起流行"动宾，动宾"双句式（前半措施+后半目的，如"实施扩大内需战略，推动经济发展方式加快转变"，2020 年）；副词修饰词逐代更替（大力/切实→着力/扎实→加紧/更大力度）。→ 标题技巧（小标题）

## 收尾金句谱系（号召结尾的迭代规律）

- **"奋斗/实干"系收尾年年换韵、内核不变**：奋斗才能赢得未来（2016）→ 实干铸就辉煌（2017）→ 团结凝聚力量，实干创造未来（2018）→ 奋斗创造历史，实干成就未来（2019）→ 实干赢得未来（2023）→ 奋斗创造未来（2024）→ 实干谱写华章（2025）→ 奋进正当其时（2026）。配套固定动作：形势定位句（中华民族不畏艰难险阻，2020）+ 团结句（紧密团结在党中央周围）+ 目标句（中国梦/强国建设民族复兴）。→ 金句素材（号召结尾）
- **高频复用句位**："行稳致远"（2014/2015/2024/2025，载体可换：巨轮/航船/经济）；"有权不可任性"（2015 首创，2023 扩展为"有权不可任性，用权必受监督"）；"任何艰难险阻都挡不住…"（2001-2016 反复复用，宾语可升级：中国人民胜利前进的步伐（2001/2003）→我们前进的步伐（2006）→中华民族伟大复兴的历史进程（2010）→中国发展前行的步伐（2016）；2019/2022 变体"中国人民有战胜任何艰难险阻的勇气、智慧和力量"）。→ 金句素材（复用）

## 高频提法迭代表（首现年份经 27 份原文逐一检索核实）

- **发展定位链**：经济发展进入新常态（2015）→ 以新发展理念引领发展（2016）→ 高质量发展（2018 存档内首现，公认首提为 2017 党的十九大）→ 因地制宜发展新质生产力（2024，2026 年升级为"加紧培育壮大新动能"）。→ 理论学习（政策时效）
- **供给改革链**：供给侧结构性改革（2016）→ "三去一降一补"（2017）→ "深化供给侧结构性改革"持续沿用至 2025（与扩大内需战略结合表述为"把实施扩大内需战略同深化供给侧结构性改革有机结合"，2024）。→ 理论学习（政策时效）
- **数字链**："互联网+"（2015）→ 数字经济（2017）→ 数字中国、新一代人工智能研发应用（2018）→ 数字技术与实体经济加速融合（2022）→ "人工智能+"行动（2024）→ 人工智能等前沿领域研发应用走在世界前列（2026）。→ 理论学习（政策时效）
- **绿色低碳链**：科学发展观（2004）→ 绿色发展（2013）→ 绿水青山就是金山银山理念入报告（2018）→ 碳达峰碳中和（2021）→ 协同推进降碳减污扩绿增长（2024-2025）→ 经济社会发展全面绿色转型（2025）。→ 理论学习（政策时效）
- **三农链**：取消农业税、终结农民种田交税历史（2004-2007）→ 精准扶贫（2014）→ 脱贫攻坚（2016）→ 乡村振兴（2018）→ 乡村全面振兴（2022）→ 学习运用"千万工程"经验（2025）。→ 理论学习（政策时效）
- **开放链**：加入世贸组织（2002）→ "一带一路"（2015）→ 制度型开放（2019）→ 更高水平对外开放（2020）→ 自主开放和单边开放（2025）。→ 理论学习（政策时效）
- **现代化目标链**：全面建设小康社会（2003）→ 全面建成小康社会（2011）→ 脱贫攻坚战全面胜利、第一个百年目标实现（2021-2022）→ 中国式现代化（2023）→ 以中国式现代化全面推进强国建设、民族复兴伟业（2024-2026 固定收束表述）。→ 理论学习（政策时效）
- **政府自身建设链**：从严治政（2000）→ 科学民主决策、依法行政（2004）→ 建设服务型政府（2005）→ 人民满意的服务型政府（2010）→ 法治政府、创新政府、廉洁政府和服务型政府（2016）→ 当好贯彻党中央决策部署的执行者、行动派、实干家（2024）。→ 理论学习（政策时效）
- **宏观调控链**：有保有压（2005）→ 区间调控、定向调控（2015）→ 相机调控（2016）→ 精准调控（2018）→ 跨周期和逆周期调节（2022）→ 政策聚焦发力（2024）。→ 理论学习（政策时效）
- **纾困组合词链**：大众创业、万众创新（2015）→ "放管服"改革（2017）→ "两个毫不动摇"（2018）→ "六稳""六保"（2020）→ 助企纾困、稳市场主体（2022）→ 全国统一大市场（2022）。→ 理论学习（政策时效）

## 一级结构演变（供大材料定骨架，模板见 templates.md"政府工作报告"）

- **三段式（单年报告）**：回顾 → 主要任务 → 自身建设（2004）。**两段式（换届年）**：五年回顾 → 主要任务含自身建设（2008）。**三段式（换届年）**：五年回顾 → 总体要求/预期目标/宏观政策 → 建议（2013、2018）。**规划年**：回顾 → 五年目标任务 → 年度重点（2016）。**当代主流**：回顾 → 总体要求和政策取向 → 年度任务（任务内末项或独立项为政府自身建设，2013-2024）。**最新四段式**：回顾 → 五年目标/重大工程 → 总体要求和政策取向 → 年度任务（2026）。→ 结构方法（大材料骨架）
