# GB/T 9704-2012《党政机关公文格式》格式规范层

> 本文件为「超级公文写作 Skill」的格式规范引用。
> 来源：GB/T 9704-2012《党政机关公文格式》国家标准。
> 用途：在第5步「收果子」阶段按国标做格式校验，使输出在版式上符合党政机关公文规范。

---

## 一、标准概述

| 项目 | 内容 |
|------|------|
| 标准名称 | GB/T 9704-2012《党政机关公文格式》 |
| 发布/实施日期 | 2012年6月29日发布，2012年7月1日实施 |
| 适用范围 | 各级党政机关制发的公文；其他机关和单位的公文可参照执行 |
| 配套文件 | 《党政机关公文处理工作条例》（中办发〔2012〕14号） |
| 总体结构 | 公文版面由版头、主体、版记三部分组成，版记位于公文最后一面 |

---

## 二、版面设置

| 要素 | 规格 |
|------|------|
| 纸张 | A4（210mm×297mm） |
| 天头（上白边） | 37mm±1mm |
| 订口（左白边） | 28mm±1mm |
| 版心 | 156mm×225mm（由天头、订口围出，居中进行排版） |
| 版面密度 | 每页 22 行、每行 28 字（撑满版心）；情形特殊时可适当调整 |
| 行距 | 28 磅（与 3 号正文配套，即每页 22 行的行间距离） |
| 计量单位"行" | 一行 = 一个汉字的高度 + 3 号汉字高度的 7/8 的距离（标示公文中纵向距离的长度单位）（GB/T 9704-2012） |
| 字宽对应 | 3 号字单字宽约 5.6mm，每行 28 字约 156mm，恰与版心宽度吻合 |
| 缩进 | 正文每自然段首行左空二字，回行顶格 |
| 装订 | 左侧装订（订口侧），一般用骑马订或平订，装订不遮盖版心文字；订位为两钉外订眼距版面上下边缘各 70mm 处（允许误差±4mm），骑马订钉锯均订在折缝线上，平订钉锯与书脊间的距离为 3mm~5mm（GB/T 9704-2012） |
| 颜色 | 除发文机关标志、红色分隔线用红色外，其余文字均为黑色 |
| 印刷质量 | 双面印刷，页码套正（两面误差不超过 2mm）；黑色油墨达到色谱所标 BL100%，红色油墨达到 Y80%、M80%；印品着墨实、均匀，字面不花、不白、无断划（GB/T 9704-2012） |

## 三、字体字号规范表

| 要素 | 字体 | 字号 |
|------|------|------|
| 标题 | 小标宋体字，居中排布 | 2 号 |
| 正文 | 仿宋_GB2312 | 3 号 |
| 一级标题（一、） | 黑体 | 3 号 |
| 二级标题（（一）） | 楷体_GB2312 | 3 号 |
| 三级标题（1.） | 仿宋_GB2312 | 3 号 |
| 四级标题（（1）） | 仿宋_GB2312 | 3 号 |
| 版记（抄送机关、印发机关和印发日期） | 仿宋_GB2312 | 4 号 |
| 页码 | 宋体（半角阿拉伯数字） | 4 号 |

**注**：正文中引用上级文件时，文件名称用书名号《》；文中阿拉伯数字与对应单位符号之间不留空格（GB/T 15835 数字用法另作参照）。特殊确需强调的，可用 3 号仿宋加粗；不属于规范要求时，不擅自变字号。

## 四、结构层次序数

| 层级 | 序数样式 | 编排位置 | 字体 |
|------|----------|----------|------|
| 第一层 | 一、 | 左空二字，独立成行 | 黑体，3 号 |
| 第二层 | （一） | 左空二字 | 楷体_GB2312，3 号 |
| 第三层 | 1. | 左空二字 | 仿宋_GB2312，3 号 |
| 第四层 | （1） | 左空二字 | 仿宋_GB2312，3 号 |

**使用规则**：
- 按层级顺序使用，不得重级、跳级；用完第一层才可进入第二层
- "一、"后标顿号；"1."后标实心圆点；括号式序数（（一）（1））后不再加标点
- 同一层级序号全文形式必须一致
- 层次过细时可夹用"①②③"等，仅用于文内分项，不占序数层级

## 五、版头部分要素

| 要素 | 编排规定 |
|------|----------|
| 份号 | 涉密公文应标注份号，用 6 位 3 号阿拉伯数字，顶格编排在版心左上角第一行 |
| 密级和保密期限 | 顶格编排在版心左上角第二行；密级用"绝密""机密""秘密"，与保密期限之间用"★"隔开 |
| 紧急程度 | 顶格编排在版心左上角第三行；同时标注份号、密级、紧急程度时，按份号→密级→紧急程度自上而下编在第 1~3 行 |
| 发文机关标志 | 红色小标宋体字居中排布，用发文机关全称或规范化简称后加"文件"二字；上边缘至版心上边缘为 35mm（信函格式为上边缘至上页边 30mm）（GB/T 9704-2012） |
| 发文字号 | 机关代字＋〔年份〕＋序号，如"×政发〔2026〕12号"；年份用阿拉伯数字全称、六角括号〔〕括入；序号不编虚位、不加"第"字 |
| 行文方向判定 | 上行文（报告、请示等）须标注签发人；平行文、下行文一般不标注 |
| 发文字号位置 | 居发文机关标志下空二行位置；上行文时发文字号居左空一字，右侧排签发人 |
| 签发人 | 上行文应标注签发人姓名，右空一字编排在发文字号同一行右侧；签发人姓名与发文字号同行 |
| 红色分隔线 | 版头与主体之间用一条红色反线（红色分隔线）隔开，居版心中部贯穿 |

## 六、主体部分要素

| 要素 | 编排规定 |
|------|----------|
| 标题 | 2 号小标宋体居中编排在红色分隔线下空二行位置；回行时排列对称、长短适宜，采用梯形或菱形排列，不使词意割裂 |
| 主送机关 | 标题下空一行，居左顶格，回行仍顶格，最后一个机关名后标全角冒号 |
| 正文 | 首页必须显示正文（不出现"此页无正文"）；每自然段左空二字，回行顶格；正文中的年份、数字等不得随意换行 |
| 附件说明 | 正文下空一行，左空二字编排"附件"及附件名称，附件名称后不加标点；多个附件用（一）（二）分列 |
| 文号引用 | 正文引用政策依据时，首次出现须写全文件名称加文号（如：《关于开展XX工作的通知》（×政发〔2026〕8号）） |
| 发文机关署名 | 成文日期之上、以成文日期为准居中编排 |
| 成文日期 | 用阿拉伯数字标全年月日（如"2026年8月19日"），右空四字 |
| 印章 | 印章端正、居中，下压发文机关署名和成文日期，使署名与日期居于印章中央偏下；用印不得出现空白印章 |
| 附注 | 成文日期下一行左空二字加圆括号编排，如：（此件发至县级各机关） |
| 附件 | 附件应另面编排、与正文装订，在附件左上角第一行顶格标注"附件"及序号；应在版记之前编排，"附件"二字及附件顺序号用 3 号黑体（GB/T 9704-2012） |

---

## 七、版记部分要素

| 要素 | 编排规定 |
|------|----------|
| 版记位置 | 版记应置于公文最后一面（一般为偶数页），分隔线贯穿 |
| 抄送机关 | 版记首条分隔线之下居左空二字，后标全角冒号，回行时与冒号后首字对齐 |
| 印发机关和印发日期 | 抄送机关下一行，印发机关居左空一字，印发日期居右空一字 |
| 分隔线 | 抄送机关与印发机关之间、版记顶与底各设一条分隔线，将各要素区隔；分隔线与版心等宽，首条与末条用粗线（推荐高度 0.35mm），中间用细线（推荐高度 0.25mm）（GB/T 9704-2012） |
| 页码 | 4 号半角宋体阿拉伯数字，数字左右各放一条一字线，置于版心下边缘之下，一字线上距版心下边缘 7mm；单页码居右空一字，双页码居左空一字（GB/T 9704-2012） |

## 八、15 种法定文种

依据 2012 年《党政机关公文处理工作条例》规定，法定公文共 15 种：

| 序号 | 文种 | 序号 | 文种 |
|------|------|------|------|
| 1 | 决议 | 9 | 通报 |
| 2 | 决定 | 10 | 报告 |
| 3 | 命令（令） | 11 | 请示 |
| 4 | 公报 | 12 | 批复 |
| 5 | 公告 | 13 | 议案 |
| 6 | 通告 | 14 | 函 |
| 7 | 意见 | 15 | 纪要 |
| 8 | 通知 | | |

**适用提示**：选文种时先判行文关系（上行/平行/下行），再对应法定文种，避免"请示"与"报告"混用、平行文使用"命令""决议"等错位。

## 九、公文的特定格式（GB/T 9704-2012）

| 特定格式 | 编排规定 |
|------|------|
| 信函格式 | 发文机关标志用全称或规范化简称，居中排布，上边缘至上页边 30mm；发文机关标志下 4mm 处印一条红色双线（上粗下细），距下页边 20mm 处印一条红色双线（上细下粗），线长均为 170mm、居中排布；首页不显示页码，版记不加印发机关和印发日期、分隔线 |
| 命令（令）格式 | 发文机关标志由发文机关全称加"命令"或"令"字组成，居中排布，上边缘至版心上边缘 20mm；标志下空二行居中编排令号，令号下空二行编排正文 |
| 纪要格式 | 纪要标志由"×××××纪要"组成，居中排布，上边缘至版心上边缘 35mm，推荐使用红色小标宋体字 |
