# 18种常用文体框架模板速查

> 本文件为「超级公文写作 Skill」的文体模板引用。
> 来源：顿彬《公文写作算法》第三章完整框架 + 李永新《笔杆子是怎样炼成的》第五章模板整合。

---

## 使用说明

- 每种文体标注了**成分构成**（干货/水分比例）
- **干货** = 工作措施/工作计划/工作目标/成绩数据
- **水分** = 意义/背景/形势/引用/问题/举例/故事/正反论证/要求/感谢/号召
- 根据文体类型自动选择对应的模板框架

---

## T1. 工作简报

| 组件 | 内容 |
|------|------|
| **标题** | 独角兽型 / 双子座型 |
| **首段** | 时间状语 + 按 + 拿 + 推 |
| **主体部分**（3~5 个分点） | 每个分点：措施 + 成绩（重点讲成绩和产品化名词） |

**特征**：全部由「措施」+「成绩」组成（干货型）、不含水分成分。

---

## T2. 工作计划

| 组件 | 内容 |
|------|------|
| **标题** | ××年工作计划 / 要点 |
| **首段** | 工作思路：按 + 拿 + 推 |
| **主体部分**（3 个分点以上） | 每个分点：计划 + 目标（重点讲产品化名词） |

**语言特征**：几乎全部 V+N 结构、剧情只占少量、数字为大概而非精准、篇幅比工作总结短。

---

## T3. 工作总结

| 组件 | 内容 |
|------|------|
| **标题** | ××年工作总结 |
| **首段** | 时间状语 + 按 + 拿 + 推 |
| **一、工作完成情况**（必备） | 措施 + 成绩（重点讲成绩、剧情、产品化名词） |
| **二、存在的问题** | 问题成分 |
| **三、下一步打算** | 计划 + 目标（重点讲产品化名词） |

> 注意：存在问题、下一步打算两个部分看情况决定是否写（问上级领导，看过去的写作习惯）。

## T4. 工作报告（政府级）

| 大板块 | 子模块 | 成分 |
|--------|--------|------|
| **标题** | ××年工作报告 | — |
| **首段** | 约定俗成，直接借用上一年 | — |
| **一、××年工作情况** | 1.整体完成情况 | 背景+按+拿+推 |
| | 2.主要成绩 | 最拿得出手的工作名词+数字 |
| | 3.主要做法 | 工作措施+成绩（突出动词） |
| | 4.表示感谢 | 感谢成分 |
| | 5.存在问题 | 问题成分 |
| **二、下一年工作计划** | 1.形势分析 | 机遇与挑战 |
| | 2.明年工作目标 | 工作指标/重大型工作 |
| | 3.明年工作思路 | 按+拿+推 |
| | 4.主要工作安排 | 工作计划 |
| **结尾** | 号召 | 同志们+引用+工作要求+三组四字句+近目标+远目标 |

## T5. 心得体会

| 组件 | 内容 |
|------|------|
| **标题** | 独角兽型 / 双子座型 |
| **首段** | 背景（大背景+小背景）+感触+引出后文 |
| **主体部分** | 每个一级标题下分为2-3个分点，每个分点=**水分**（意义/背景/形势/引用/问题/举例/故事/正反论证/假设/成绩）+**干货**（工作措施） |
| **结尾** | 号召 |

> 关键逻辑：经历一场"活动或工作"→引起新的认识→促进自己好好干工作（从虚到实、从知到行）。落脚点永远是谈接下来如何做。

## T6. 领导讲话（四种分类）

### A. 事前类（工作部署会议、动员大会）

| 板块 | 内容 |
|------|------|
| **标题** | 独角兽型 / 双子座型 |
| **首段** | 会议大背景+小背景+要求+引出后文 |
| **一、思想意义层面**（侧重"因"） | 每个分点：水分（意义/背景/形势/引用等）+干货（工作要求） |
| **二、核心工作** | 每个分点：水分+干货（工作措施） |
| **三、对内要求** | 每个分点：水分+干货（工作措施） |
| **结尾** | 号召 |

### B. 事中类（推进会、调度会）

> 在事前类基础上，第一部分替换为：
> **一、成绩+问题层面** — 分点一：主要成绩；分点二：主要做法；分点三：主要问题
> 其余部分与事前类一致。

### C. 事后类（总结表彰大会）

> 结构同事中类，三个大板块不变，但更侧重成绩复盘和经验总结。

### D. 特殊类（专题讲话、培训班讲话）

| 板块 | 内容 |
|------|------|
| **一、措施1** | 每个分点：水分+干货（工作措施） |
| **二、措施2** | 同上 |
| **三、措施3** | 同上 |

> 即去掉"思想意义"和"对内要求"，全篇围绕具体措施展开。

## T7. 工作通知（三种子类）

### A. 通用型通知

| 组件 | 内容 |
|------|------|
| **标题** | 关于×××的通知 |
| **首段** | 大背景+小背景+目的。经×××研究，决定……现将工作通知如下 |
| **前：工作精神来源** | 背景+目标 |
| **中：核心任务** | 核心名词 |
| **后：对内要求** | 工作要求 |

### B. 会议通知

| 组件 | 内容 |
|------|------|
| **首段** | 大背景+小背景+目的。经×××研究，决定召开。现将会议通知如下 |
| **前：四要素** | 主题/时间/地点/人物 |
| **中：会议议程** | 主要环节、议程、安排 |
| **后：会议要求** | 上报名单/资料、注意事项、联系人 |

### C. 印发文件通知

| 组件 | 内容 |
|------|------|
| **首段** | 起因目的+根据上级精神+现将《×××》印发给你们，请结合实际抓好落实 |
| **主体** | 相关文件原文 |

## T8. 工作方案（两种类型）

### A. 完整型

| 组件 | 内容 |
|------|------|
| **标题** | V+N + 工作方案 |
| **首段** | 大背景+小背景+目的+特制定以下方案 |
| **一、总体要求** | 指导思想/基本原则/工作目标 |
| **二、主要任务** | 核心名词 |
| **三、工作措施** | 工作要求 |

### B. 直接型

| 组件 | 内容 |
|------|------|
| **首段** | 大背景+小背景+目的+特制定以下方案 |
| **对外措施** | V+N ——重点是核心名词 |
| **对内措施** | 强化组织领导/明确责任分工/强化督导考核/加大工作宣传/强化思想作风/开展人才培养 |

## T9. 调研报告（两种方向）

### A. 调研经验型（取经）

| 组件 | 内容 |
|------|------|
| **标题** | 关于×××的调研报告 |
| **首段** | 大背景+小背景+调研实施过程+引出后文 |
| **一、主要情况** | 中性地介绍调研对象（地理位置/人口/经济/过往发展） |
| **二、主要工作做法** | 调研对象的成绩和措施 |
| **三、经验及建议** | 将调研对象的措施转移到自身单位 |

### B. 调研问题型（找问题）

| 组件 | 内容 |
|------|------|
| **一、主要情况** | 同上 |
| **二、主要存在的问题** | 调研对象自身问题 |
| **三、经验及建议** | 问题解决办法 |

## T10. 党课

> 框架与**事前类领导讲话**完全一致（三段式：思想意义+核心工作+对内要求），内容上专门侧重党的理论方面。最核心：成分+剧情是否完全驾驭。

---

## T11. 微型党课/演讲（三种）

### A. 古板型

| 组件 | 内容 |
|------|------|
| **标题** | 独角兽型 / 双子座型 |
| **首段** | 故事 |
| **一~三、观点** | 水分（意义/背景/引用/故事/举例）+干货（工作要求） |
| **结尾** | 号召 |

### B. 新颖型

| 阶段 | 动作 |
|------|------|
| 开头 | 故事引出 → 直截了当直击主题 |
| 点题 | 拔高到核心 |
| 展开 | 回顾历史："历史三连" |
| 收回 | 回到现在 → 对接顶层 |
| 下降 | 回到自己 → 谈自身当前工作 |
| 结尾 | 号召 → 再次点题 |

### C. 极限黄金型

| 阶段 | 动作 |
|------|------|
| 开头 | 故事引出（以书或故事开头） |
| 引申 | 故事拔高（使用红色故事） |
| 展开 | 分析三连（三个重要意义） |
| 收回 | 回到自己（使用主题对接自身） |
| 分解 | 分成三个要求（融合第一种微型党课） |
| 结尾 | 号召 → 回到自身+对接顶层+再次点题 |

## T12. 会议纪要（两种形态）

### A. 一事一议型

| 组件 | 内容 |
|------|------|
| **标题** | （按本单位格式） |
| **首段** | 会议基本情况 |
| **审议通过A事件** | 简要介绍情况→结果→下一步安排 |
| **研究讨论B事件** | 同上 |
| **研究讨论C事件** | 同上 |

### B. 会议新闻型

| 组件 | 内容 |
|------|------|
| **会议指出** | 意义、方向、重大工作要求 |
| **会议认为** | 结果性判断 |
| **会议明确** | 工作任务和责任的明确 |
| **会议强调** | 核心重点工作（最重要的部分，按分点撰写） |
| **会议要求** | 对内工作要求 |

> 核心原则：会议纪要**只保留一把手最后决定的内容和意见**，其他人发言全部删掉。格式参照本单位过去纪要。

## T13. 新闻稿（三种类型）

### A. 会议新闻

| 组件 | 内容 |
|------|------|
| **标题** | 直截了当地表达某单位召开的某会议 |
| **首段** | 时间+地点+人物+事件（四要素。市级以上只出现一把手；县级以下可出现其他领导） |
| **会议详情** | 会议背景、议程、流程（部分可省略） |
| **领导讲话详情** | 会议指出→会议认为→会议明确→会议强调→会议要求 |

### B. 活动新闻

| 组件 | 内容 |
|------|------|
| **标题** | 直截了当表达某单位开展了某活动 |
| **首段** | 四要素（领导排序规则同上） |
| **活动经过** | 以官方活动安排流程为参照，写重要节点 |
| **活动影响** | 附加品——活动立刻产生的效果 |

### C. 调研新闻

| 组件 | 内容 |
|------|------|
| **标题** | 直截了当介绍某领导到某单位/地区调研 |
| **首段** | 四要素，重点突出主要领导 |
| **调研的过程** | 按活动经过写法：领导先到某地慰问→再到某地交流→最后检查 |
| **会议的过程** | 被调研对象汇报工作→分管领导/部门补充 |
| **会议详情** | 上肯定→传达精神→部署下一步工作 |

## T14. 通讯稿

| 组件 | 内容 |
|------|------|
| **标题** | 实标题（直截了当）+虚标题（漂亮表述） |
| **前部分**（2-4段） | 小故事开头→整体工作情况与数据（宏观的以小见大） |
| **主体部分**（3-5个分点） | 每个分点=故事开头→制造问题冲突→宣传单位提出的解决措施和办法→解决问题作出成绩 |

**核心技巧**：
- 以小见大：在文章最前面和每部分最前面用小场景或人物开场
- 更多语言旁白/人物对话（将干货故意改成对话旁白形式）
- 制造冲突后解决问题：从易到难三个阶段——"英雄之旅"模型

## T15. 先进事迹

| 写法 | 适用场景 | 特点 |
|------|----------|------|
| **工作简报式** | 内部上报事迹（表彰/档案存档） | 只有干货，没有水分；大标题直接写"×××先进事迹"；首段交代姓名/出生日期/政治面貌/任职/大成绩/获奖情况 |
| **通讯稿式** | 对外宣传（报纸媒体） | 有故事性、有情节，水分多、干货少 |

## T16. 民主生活会对照检查材料

| 组件 | 内容 |
|------|------|
| **标题** | （按通知要求） |
| **首段** | 介绍召开民主生活会之前的准备工作和取得的相关成绩 |
| **存在的主要问题** | 根据上级文件确定分点（无成绩部分，以问题为主导） |

| **下一步整改** | 针对存在的问题一一对应提出解决措施 |

## T17. 述职报告

| 要点 | 说明 |
|------|------|
| **框架来源** | 无固定框架——必须根据上级组织部门通知要求确定 |
| **核心内容** | 全部是工作成绩，不谈问题 |
| **与个人总结的区别** | 述职报告：领导使用、规范度高、进入个人档案；个人总结：普通干部使用、非规范、不进入档案 |

## T18. 理论文章

> 整体架构与**事前类领导讲话**几乎相同（三段式），区别在于：理论文章全用书面语、领导讲话会有口语化表述。
>
> 理论文章中的背景/意义/形势/解释/问题/引用等水分成分可以直接借用到领导讲话、心得体会、党课、调研中。
