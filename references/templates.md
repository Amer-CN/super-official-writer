# 21种常用文体框架模板速查

> 本文件为「超级公文写作 Skill」的文体模板引用。
> 来源：顿彬《公文写作算法》第三章完整框架 + 李永新《笔杆子是怎样炼成的》第五章模板整合。

---

## 使用说明

- 每种文体标注了**成分构成**（干货/水分比例）
- **干货** = 工作措施/工作计划/工作目标/成绩数据
- **水分** = 意义/背景/形势/引用/问题/举例/故事/正反论证/要求/感谢/号召
- 根据文体类型自动选择对应的模板框架

---

## T1. 工作简报

| 组件 | 内容 |
|------|------|
| **标题** | 独角兽型 / 双子座型 |
| **首段** | 时间状语 + 按 + 拿 + 推 |
| **主体部分**（3~5 个分点） | 每个分点：措施 + 成绩（重点讲成绩和产品化名词） |

**特征**：全部由「措施」+「成绩」组成（干货型）、不含水分成分。

---

## T2. 工作计划

| 组件 | 内容 |
|------|------|
| **标题** | ××年工作计划 / 要点 |
| **首段** | 工作思路：按 + 拿 + 推 |
| **主体部分**（3 个分点以上） | 每个分点：计划 + 目标（重点讲产品化名词） |

**语言特征**：几乎全部 V+N 结构、剧情只占少量、数字为大概而非精准、篇幅比工作总结短。

---

## T3. 工作总结

| 组件 | 内容 |
|------|------|
| **标题** | ××年工作总结 |
| **首段** | 时间状语 + 按 + 拿 + 推 |
| **一、工作完成情况**（必备） | 措施 + 成绩（重点讲成绩、剧情、产品化名词） |
| **二、存在的问题** | 问题成分 |
| **三、下一步打算** | 计划 + 目标（重点讲产品化名词） |

> 注意：存在问题、下一步打算两个部分看情况决定是否写（问上级领导，看过去的写作习惯）。

> 风格实测（lieflat-gongwen 229 篇语料）：本模板对应"经验总结"文种（n=8，样本薄仅供参考）——句长中位 64（58-71），为各文种最长档；强制词 0-1 个/篇；样本 100% 零百分比，不掌握真实数据时不编造。

## T5. 心得体会

| 组件 | 内容 |
|------|------|
| **标题** | 独角兽型 / 双子座型 |
| **首段** | 背景（大背景+小背景）+感触+引出后文 |
| **主体部分** | 每个一级标题下分为2-3个分点，每个分点=**水分**（意义/背景/形势/引用/问题/举例/故事/正反论证/假设/成绩）+**干货**（工作措施） |
| **结尾** | 号召 |

> 关键逻辑：经历一场"活动或工作"→引起新的认识→促进自己好好干工作（从虚到实、从知到行）。落脚点永远是谈接下来如何做。

## T6. 领导讲话（四种分类）

### A. 事前类（工作部署会议、动员大会）

| 板块 | 内容 |
|------|------|
| **标题** | 独角兽型 / 双子座型 |
| **首段** | 会议大背景+小背景+要求+引出后文 |
| **一、思想意义层面**（侧重"因"） | 每个分点：水分（意义/背景/形势/引用等）+干货（工作要求） |
| **二、核心工作** | 每个分点：水分+干货（工作措施） |
| **三、对内要求** | 每个分点：水分+干货（工作措施） |
| **结尾** | 号召 |

### B. 事中类（推进会、调度会）

> 在事前类基础上，第一部分替换为：
> **一、成绩+问题层面** — 分点一：主要成绩；分点二：主要做法；分点三：主要问题
> 其余部分与事前类一致。

### C. 事后类（总结表彰大会）

> 结构同事中类，三个大板块不变，但更侧重成绩复盘和经验总结。

### D. 特殊类（专题讲话、培训班讲话）

| 板块 | 内容 |
|------|------|
| **一、措施1** | 每个分点：水分+干货（工作措施） |
| **二、措施2** | 同上 |
| **三、措施3** | 同上 |

> 即去掉"思想意义"和"对内要求"，全篇围绕具体措施展开。

> 风格实测（lieflat-gongwen 229 篇语料）：要求词 35-55 个/篇（中位 45）为各文种最高档；句长 48-64（中位 56）；号召/展望式收尾仅 11%（75% 自然收束，收尾勿过度程式化）；三级标题为 0，层级只用两层。

## T8. 工作方案（两种类型）

### A. 完整型

| 组件 | 内容 |
|------|------|
| **标题** | V+N + 工作方案 |
| **首段** | 大背景+小背景+目的+特制定以下方案 |
| **一、总体要求** | 指导思想/基本原则/工作目标 |
| **二、主要任务** | 核心名词 |
| **三、工作措施** | 工作要求 |

### B. 直接型

| 组件 | 内容 |
|------|------|
| **首段** | 大背景+小背景+目的+特制定以下方案 |
| **对外措施** | V+N ——重点是核心名词 |
| **对内措施** | 强化组织领导/明确责任分工/强化督导考核/加大工作宣传/强化思想作风/开展人才培养 |

> 风格实测（lieflat-gongwen 229 篇语料）：顿号 14-22‰ 为各文种最疏档（规范性文件易并列过度，注意克制）；三级标题是本文种特色（中位 11 个、区间 5-17，n=10 样本薄仅供参考）；重心为单段独大型——最重一段常见 37-58%（中位 46%）。

> **任务块指引（评测 P0-1）**："二、主要任务"的任务呈现默认用行首 `1.` 三级条目，每条 = 一项任务 + 一项举措 + 一个时间节点；避免写成"一是…七是"的自然段大段——工作方案"一是二是"参数为 0-2 次，大段罗列直接顶破。注意 check_params 的"重心"按一级标题区块切分（非自然段），把任务堆成一个自然段会同时抬高"最重一段占比"。

## T9. 调研报告（两种方向）

### A. 调研经验型（取经）

| 组件 | 内容 |
|------|------|
| **标题** | 关于×××的调研报告 |
| **首段** | 大背景+小背景+调研实施过程+引出后文 |
| **一、主要情况** | 中性地介绍调研对象（地理位置/人口/经济/过往发展） |
| **二、主要工作做法** | 调研对象的成绩和措施 |
| **三、经验及建议** | 将调研对象的措施转移到自身单位 |

### B. 调研问题型（找问题）

| 组件 | 内容 |
|------|------|
| **一、主要情况** | 同上 |
| **二、主要存在的问题** | 调研对象自身问题 |
| **三、经验及建议** | 问题解决办法 |

> 风格实测（lieflat-gongwen 229 篇语料）："一是二是"0-12 次/篇为各文种最宽（中位 9，四分之一作品完全不用）；重心均衡型——最重一段常见 35-49%（中位 41%）；真实公文 75-87% 自然收束，勿加程式化结语。

## T10. 党课

> 框架与**事前类领导讲话**完全一致（三段式：思想意义+核心工作+对内要求），内容上专门侧重党的理论方面。最核心：成分+剧情是否完全驾驭。

## T11. 微型党课/演讲（三种）

### A. 古板型

| 组件 | 内容 |
|------|------|
| **标题** | 独角兽型 / 双子座型 |
| **首段** | 故事 |
| **一~三、观点** | 水分（意义/背景/引用/故事/举例）+干货（工作要求） |
| **结尾** | 号召 |

### B. 新颖型

| 阶段 | 动作 |
|------|------|
| 开头 | 故事引出 → 直截了当直击主题 |
| 点题 | 拔高到核心 |
| 展开 | 回顾历史："历史三连" |
| 收回 | 回到现在 → 对接顶层 |
| 下降 | 回到自己 → 谈自身当前工作 |
| 结尾 | 号召 → 再次点题 |

### C. 极限黄金型

| 阶段 | 动作 |
|------|------|
| 开头 | 故事引出（以书或故事开头） |
| 引申 | 故事拔高（使用红色故事） |
| 展开 | 分析三连（三个重要意义） |
| 收回 | 回到自己（使用主题对接自身） |
| 分解 | 分成三个要求（融合第一种微型党课） |
| 结尾 | 号召 → 回到自身+对接顶层+再次点题 |

## T12. 会议纪要（两种形态）

### A. 一事一议型

| 组件 | 内容 |
|------|------|
| **标题** | （按本单位格式） |
| **首段** | 会议基本情况 |
| **审议通过A事件** | 简要介绍情况→结果→下一步安排 |
| **研究讨论B事件** | 同上 |

| 组件 | 内容 |
|------|------|
| **会议指出** | 意义、方向、重大工作要求 |

## T13. 新闻稿（三种类型）

### A. 会议新闻

| 组件 | 内容 |
|------|------|
| **标题** | 直截了当地表达某单位召开的某会议 |
| **首段** | 时间+地点+人物+事件（四要素。市级以上只出现一把手；县级以下可出现其他领导） |
| **会议详情** | 会议背景、议程、流程（部分可省略） |
| **领导讲话详情** | 会议指出→会议认为→会议明确→会议强调→会议要求 |

### B. 活动新闻

| 组件 | 内容 |
|------|------|
| **标题** | 直截了当表达某单位开展了某活动 |
| **首段** | 四要素（领导排序规则同上） |
| **活动经过** | 以官方活动安排流程为参照，写重要节点 |
| **活动影响** | 附加品——活动立刻产生的效果 |

### C. 调研新闻

| 组件 | 内容 |
|------|------|
| **标题** | 直截了当介绍某领导到某单位/地区调研 |
| **首段** | 四要素，重点突出主要领导 |
| **调研的过程** | 按活动经过写法：领导先到某地慰问→再到某地交流→最后检查 |
| **会议的过程** | 被调研对象汇报工作→分管领导/部门补充 |
| **会议详情** | 上肯定→传达精神→部署下一步工作 |

## T14. 通讯稿

| 组件 | 内容 |
|------|------|
| **标题** | 实标题（直截了当）+虚标题（漂亮表述） |
| **前部分**（2-4段） | 小故事开头→整体工作情况与数据（宏观的以小见大） |
| **主体部分**（3-5个分点） | 每个分点=故事开头→制造问题冲突→宣传单位提出的解决措施和办法→解决问题作出成绩 |

**核心技巧**：
- 以小见大：在文章最前面和每部分最前面用小场景或人物开场
- 更多语言旁白/人物对话（将干货故意改成对话旁白形式）
- 制造冲突后解决问题：从易到难三个阶段——"英雄之旅"模型

## T18. 理论文章

> 整体架构与**事前类领导讲话**几乎相同（三段式），区别在于：理论文章全用书面语、领导讲话会有口语化表述。

## T19. 政府工作报告（大材料骨架，历年报告实测）

> 依据 2004/2008/2013/2016/2022/2026 六份里程碑年报告的一级结构提炼（27 份原文见 `sources/gongzuobaogao/`；分年结构观察见 corpus"报告蒸馏层"）。适用于年度/五年综合性大报告、全局性工作总报告。

### 一级结构骨架（四段式，2026 年最新形态）

| 板块 | 内容 | 成分与句式 |
|------|------|-----------|
| **开场段** | "各位代表：现在，我代表××，向大会报告工作，请予审议" | 约定俗成固定句（直接沿用惯例） |
| **一、工作回顾**（篇幅约 1/3-1/2） | 帽段定性（"极不平凡的一年/里程碑意义的一年"+形势定位）→ 成绩分条 → 问题不足 | 成绩条目用 **N+V 对仗小标题+量化数据**（"——经济运行总体平稳。"），每条领域排序：经济→结构/创新→改革→生态→民生；问题段单列或并入帽段 |
| **二、总体要求和政策取向**（规划年单列为"五年目标"） | 指导思想 → 主要预期目标（量化指标逐项列）→ 政策取向/工作总基调 | 总基调句："坚持稳中求进工作总基调，完整、准确、全面贯彻新发展理念"；目标多为"数字+左右" |
| **三、主要任务/重点工作**（篇幅约 1/2） | 按领域分 8-10 块：宏观政策/内需→产业/科技→改革→开放→农业乡村→区域城镇→绿色→民生→安全 | 每块 **V+N 对仗小标题**（"着力扩大国内需求""加快发展新质生产力"），2000-2012 单句式、2014 起"动宾，动宾"双句式 |
| **四、政府自身建设**（当代多并入任务末项） | 政治建设→法治→作风→廉政 | 排比式 V+N 短句（建设…政府） |
| **结尾** | 号召 | 固定谱系："形势定位句+团结句+目标句"，"奋斗/实干"系金句年年换韵（见 phrase-library 第十节） |

### 变体（按会议年份选用）

| 年型 | 一级结构 | 实测来源年份 |
|------|----------|--------------|
| 单年报告 | 回顾 → 主要任务 → 自身建设 | 2004 |
| 换届年（五年） | 五年回顾 → 主要任务（含自身建设） | 2008 |
| 换届年（五年） | 五年回顾 → 总体要求/预期目标/宏观政策 → 建议 | 2013 |
| 规划开局年 | 回顾 → 五年目标任务和重大举措 → 年度重点 | 2016、2021 |
| 当代主流 | 回顾 → 总体要求和政策取向 → 年度任务 | 2022 |
| 最新四段式 | 回顾 → 五年目标/重大任务/重大工程 → 总体要求和政策取向 → 年度任务 | 2026 |

> 句式配比基准：总结回顾段 N+V ≥30%（早年报告可达 40%+），部署任务段 V+N ≥80%（实测均值 94.7%）——见 SKILL.md"文章类型判断"实测依据与 vnv_stats.md。
